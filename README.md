# 🤖 AI Chatbot NLP Project

An intelligent NLP-based chatbot built using Python, Flask, Scikit-learn, NLTK, SQLite, and VADER Sentiment Analysis.

## 🚀 Features

* Intent-based chatbot using Machine Learning
* NLP text preprocessing with NLTK
* Sentiment Analysis using VADER
* Confidence score prediction
* Chat history storage using SQLite
* Analytics Dashboard
* Sentiment distribution charts using Chart.js
* Responsive web interface
* GitHub version control

## ⚙️ Installation

### Clone Repository
git clone https://github.com/Tanmaya19D/AI-CHATBOT-NLP.git
cd AI-CHATBOT-NLP


### Create Virtual Environment
python -m venv .venv


### Activate Virtual Environment

Windows:
.venv\Scripts\activate


### Install Dependencies
pip install -r requirements.txt


## ▶️ Run the Project

Start Flask Application:
python app.py


Open browser:

http://127.0.0.1:5000
